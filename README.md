# Starter Simple Demo

Starter Simple Demo is a minimal application showing how to assemble the
Golang Acexy starter modules without using the higher-level cloud packages.

It demonstrates:

- lifecycle management with `starter-parent`
- HTTP routing with `starter-gin`
- MySQL access with `starter-gorm`
- Redis cache-aside access with `starter-redis`
- coordinated startup and shutdown

## Requirements

- Go 1.25.8 or later
- MySQL on `127.0.0.1:13306`
- Redis on `127.0.0.1:6379`

The default local credentials are examples only. Change them before using this
project outside a local development environment.

## Database

Create the demo table:

```bash
mysql -h 127.0.0.1 -P 13306 -u root -p test < docs/sql.sql
```

The model uses explicit starter-gorm conventions:

- `ID` is the primary key and is generated by MySQL
- `CreateTime` and `UpdateTime` are generated by MySQL
- `StudentMapper` embeds `gormstarter.BaseMapper[Student]`

## Starter Assembly

The application registers starters in dependency order:

1. GORM
2. Redis
3. Gin

```go
starterLoader := parent.InitStarterLoader(loadStarter())
if err := starterLoader.Start(); err != nil {
    return
}

sys.ShutdownHolding()
_, _ = starterLoader.StopAllBySetting(30 * time.Second)
```

Gin starts last so HTTP traffic is accepted only after database and cache
dependencies are ready. Shutdown runs in reverse lifecycle order.

## Run

```bash
GOMODCACHE=/Users/acexy/Repository/cache/golang go run ./bin
```

The HTTP server listens on `http://127.0.0.1:8080`.

## API

Create a student:

```bash
curl -sS -X POST http://127.0.0.1:8080/student/save \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "John Doe",
    "age": 20,
    "sex": 0,
    "teacherId": 1
  }'
```

Query the student:

```bash
curl -sS http://127.0.0.1:8080/student/get/1
```

The query endpoint uses cache-aside behavior:

1. read the student from Redis
2. fall back to MySQL on a cache miss or Redis read error
3. write the database result back to Redis
4. return the database result even if cache write-back fails

The cache entry expires after ten seconds.

Additional manual requests are available in `docs/http-call.http`.

## Design Notes

- The demo uses one package-level stateless `StudentMapper`.
- Database errors are returned to the Gin starter error pipeline.
- Invalid and missing student IDs return a bad-parameter response.
- Redis failures do not make an otherwise successful database query fail.
- Package-owned starter instances are accessed through their public helper
  APIs; the demo does not manage raw global connections.
